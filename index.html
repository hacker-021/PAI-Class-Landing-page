Anti-Hallucination Architecture

The System Uses a Strict 'Fence' So AI Never Makes Things Up

Most AI reads the open internet, which causes mistakes, hallucinations, and false information. PAI Class is fundamentally different: our AI is strictly locked inside a boundary fence.

👩‍🏫
Step 1: Teacher Upload

Instructor uploads official course slides, lecture PDFs, and syllabus documents into the Resource Hub.

➔
🛡️
Step 2: Strict Document Fence

Poppler OCR & Mistral 1024-dim embeddings index the exact slide boundaries. No unverified internet data allowed.

➔
🎓
Step 3: Grounded Student Answer

Student receives an accurate answer citing exact slide page numbers. If it's not in the slides, the AI rejects the query.

Engineered for Reliability

Custom Software Built Specifically for Speed & Zero Clutter

PAI Class is built with lightweight, dependable code, completely bypassing heavy, bloated web tools that crash under load.

⚡
Native Typed PHP 8.4+
Runs with sub-millisecond execution directly on modern university servers with zero compilation delay and built-in session encryption.
💾
Zero-Crash SQLite 3 WAL
Complete institutional data lives in a high-concurrency WAL database (ptut.sqlite). Zero separate database servers to crash or configure.
🤖
Mistral AI & Poppler OCR
Bilingual semantic vector search with 1024-dimensional embeddings and Poppler binary text extraction across English and Urdu.
🛡️
Human-in-the-Loop Grading
AI analyzes student-to-student text similarity and drafts grades, while instructors maintain 100% authoritative final approve & release control.
🔒
Enterprise RBAC & Bcrypt
Bcrypt cost 12 password hashing, HttpOnly session cookies, CSRF protection, and role middleware protecting sensitive academic records.
🚀
Zero NPM Runtime Bloat
Pure Vanilla ES6+ Single Page Application with hash routing. No node runtime, no build tools, and zero fragile npm dependencies in production.
